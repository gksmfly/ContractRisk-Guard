실험을 다시 검증한 결과**와 외부에서 제안받은 실험 목록(§3)을 이 프로젝트 조건에 맞춰 걸러낸
결과를 담는다.

수치 인용의 단일 출처는 [`reported_numbers.md`](reported_numbers.md)다. 이 문서의 수치는 전부
`data/eval/*.json`에서 옮겼고 스크립트 경로를 같이 적었다.

## 1. 전제와 제약

1. **사람 라벨 없음.** 전문가 라벨링은 불가하다(09-06 결정, 09-28 재확인). FTC 의결서 `근거_법령`을
   규제기관의 전문가 판정으로 쓰고, 음성은 "정부 표준계약서는 적법"이라는 출처 준거로만 만든다
2. **gold 천장 255.** 조 F1 +3%p를 가리려면 n≈3,400이 필요하다. 조 F1 우열을 주장하는 실험은 설계하지 않는다
3. **사건 단위 준거의 교락 (v4 신규).** E1·E2·E3·E9가 쓰는 2,305건 모집단에서는 근거_법령을 사건의
   모든 조항에 복제해 붙인다. 이 모집단의 최적 상수(6개 조 고정)가 **F1 54.4%로 GPT(37.3%)를 포함한
   모든 라벨러를 이긴다.** 그래서 절대 F1은 해석하지 않고 상대 비교만 하며, 필터 비교에는 **문서 층화
   무작위 기준선**(같은 문서 안에서만 섞기)을 함께 낸다. 층화 전 이득의 1/4~4/5가 문서 구성 효과였다
4. **서버 침해(09-22).** E0 재현이 전부 일치해 결과 파일 변조 가능성은 낮다고 본다. 서버 보안 조치는 별개 문제
5. **방향 비대칭.** 판정 규칙은 실행 전에 이 문서에 적는다. v4의 정정 11건은 **불리 9 / 유리 1 / 중립 1**이다.
   불리: E8 철회 · CleanLab 동률 · C5 수정 · E_base 수정 · E1·E9·교차검증의 층화 축소 · AI Hub 실제 학습 수 맞춤 · E3 신뢰도 임계값 우위 소멸(OOF 재학습). 유리: E1 agreed 전사 오류 정정.
   중립: AI Hub 누수. v3까지의 재측정(유리 7 / 불리 1)과 방향이 반대다 — 이번엔 "높아 보이는 수치"를 추적했다

## 3. 외부 제안 실험 대조 — 채택·제외와 이유

09-30에 받은 일반 권고안(불공정 조항 분류 + LLM 라벨 노이즈 필터링 분야의 표준 실험)을 항목별로 걸렀다.

### 3-1. 채택 (이미 했거나 v4에서 실행)

| 제안 | 처리 | 결과 위치 |
|---|---|---|
| 계약서(문서) 단위 분할 | 이미 함 — `split_by_document()`가 문서 간 중복 55.4%까지 제거. 제안보다 엄격 | 학습 전 경로 |
| 필터 전체 vs 필터 후 vs **같은 수 무작위 제거** | E1(라벨 수준)·E8b(하류). v4에서 기준선 표본 크기 버그 수정 + 문서 층화 추가 | §4 P1-1, P1-2 |

### 3-2. 제외 — 이유

| 제안 | 제외 이유 |
|---|---|
| **Step 0: gold 300~500건 2인 라벨링 + Cohen's κ** | 사람 라벨은 이 프로젝트에서 만들 수 없다(09-06·09-28 결정). 외부 준거는 FTC 의결서(규제기관 판정)와 출처 준거뿐이다. 한계 절에 "평가자 간 일치도 미측정"으로 적는다 |
| **NOISE 판정의 사람 검수 precision** | 같은 이유. 대신 FTC 준거로 NOISE 사유별 F1을 잰다(`fbcheck_external_eval` ④) — 사람 검수의 대체 지표 |

| 근거 충실도 사람 평가 | 사람 라벨 불가. 자동 부분("evidence가 원문에 있는가")은 FB-Check의 snippet 검사 자체라 E2와 같다 |

| 재검색 횟수 0~3 ablation | 운영 검색은 약관규제법 제6~14조로 고정됐다(08-21). 재검색이 바꿀 후보 공간이 사실상 없다 |

| multi-label vs 옛 3택 도메인 정량 비교 | 옛 설계의 56.7% 탈락은 이미 정량 결과다(README, `fb_check/__main__.py`). 동기 절에 인용하면 되고 새 실험이 필요 없다 |
| "Medium 헤드 정밀도 12~13%, 소스 간 2.6배"를 부록에 | **그 수치는 08-17에 틀린 것으로 정정됐다**(고친 분할에서 Medium precision 61.9%). 인용 금지. `reported_numbers.md`의 같은 문장도 v4에서 가설로 강등 |
| Frasheri et al. (2024)를 동기로 인용 | 개인정보처리방침 QA라 과제가 다르다(v3에서도 제외) |

### P1-1 — E1 라벨 수준 ablation (재측정)

`eval/label/label_ablation.py` → `data/eval/label/label_ablation.json`. 모집단 ftc_case 2,305 (CLEAN 1,473 / NOISE 832).

**고친 것:** 옛 무작위 기준선은 빈 라벨을 이미 뺀 배열에서 "빈 포함 레코드 수(1,473)"만큼 뽑았다.
C 쪽(1,158)과 표본 크기가 달라 무작위 분포가 좁아지고 → 통과 쪽으로 기울었다.
**`reported_numbers.md`의 agreed "−1.4%p 미판정"은 agreed C를 forward용 기준선(44.3%)과 비교한 전사 오류**였다.

| 라벨 | C (FB-Check) | 무작위 B p97.5 | Δ(C−B) | 문서 층화 Δ | 판정 |
|---|---|---|---|---|---|
| forward | 46.7% (n=1,158) | 44.5% | +3.2%p (p<0.001) | **+2.4%p (p<0.001)** | 질의 효과 |
| agreed | 42.8% (n=1,150) | 42.7% | +1.1%p (p=0.020) | **+0.8%p (p=0.009)** | 질의 효과 |

- 헤드라인은 **층화 값**이다. 층화 전 이득의 약 1/4이 "쉬운 문서의 조항을 더 남긴" 효과였다
- 학습셋에 들어가는 라벨은 agreed다. agreed 이득은 작지만(+0.8%p) 유의하다

## 7. 배포 모델 교체 검토 — KoELECTRA article_v2 → KLUE-RoBERTa (사전 등록, 2026-10-05)

**동기:** paraphrase 위반 조항에서 article_v2 재현 −20.7%p, RoBERTa는 유지(P2-⑤). 같은 데이터에서 RoBERTa 조 F1 +3.8%p 경계(P1-2).

**후보:** `models/_e8_RB_s42` — 3시드 중 **dev** 제6조 제외 macro 최고(0.802 / 0.787 / 0.777). gold로 고르지 않는다.
나머지 두 시드는 안정성 확인용으로 같이 잰다.
**대조군:** `models/_e8_C_s{dev 최고}` — KoELECTRA를 현행 데이터로 학습한 것. article_v2는 **옛 데이터 963건**으로 학습돼
있어 교체는 "데이터 + 백본"이 함께 바뀐다. C로 두 효과를 나눈다(C − article_v2 = 데이터, RB − C = 백본).

| 단계 | 축 | 기각 조건 |

## 7-2. 말투 편향 줄이기 (사전 등록, 2026-10-05)

**문제:** 학습 데이터에서 위반 = 공정위 사건의 **회사 약관 말투**, 비위반 = 정부 표준계약서의 **공문서 말투**다. 모델이 내용 대신 말투를
단서로 쓸 수 있다. B4(공정한 조항을 회사 약관 말투로 바꾸면 오경보 KoELECTRA 2.6→5.9%, RoBERTa 3.7→13.2%)가 그 증거다.

**방법 — 말투를 뒤집은 사본을 학습에 더한다(반사실 증강, API 0):**
- 바꿔 쓰는 모델: Qwen2.5-14B(로컬). 뜻·당사자·숫자·조건은 유지하고 말투만 바꾼다. 자동 검사(숫자 보존·길이 0.6~1.6·실제로 바뀜) 통과분만 쓴다
- 재료는 **학습 후보에서만**: 고정 홀드아웃 12문서 제외, gold 문서는 학습기가 문서 단위로 다시 뺀다. 사본은 원본과 같은 문서 묶음에 둬 dev 누수를 막는다

| **RSN − RB** | **−11.8%p [−20.0, −3.7]** | −3.5 미판정 | −2.7 미판정 | −16.8%p [−26.6, −7.0] | **말투 편향 감소, 해 없음 → 통과** |
| RSS − RB | −9.8 미판정 | **−4.6%p 유의 감소** | +0.9 미판정 | −14.3%p | 기각 (재현 해) |

- **⚠ LLM 지문 교락 (사전에 예상한 것과 반대 방향으로 나타남):** 증강 사본·B4·paraphrase가 **모두 LLM이 다시 쓴 문장**이다.
  증강 팔이 "LLM이 다시 쓴 문장 = 공정"을 배웠다면 B4 오경보 감소의 일부와 변형문 위반 재현 하락(−14~17%p)이 같은 원인으로 설명된다.
  반면 **사람이 쓴 문장**(홀드아웃 표준계약서, 실제 기업 약관)에서도 오경보·지목률이 줄어 진짜 말투 효과도 있어 보인다. 둘을 가르려면
  사람이 쓴 회사 말투의 공정한 조항이 필요한데 그런 정답셋은 없다(한계)
- 양방향(SS)은 위반 사본이 140건뿐이라 효과가 없었고 RoBERTa에서는 재현을 해쳤다

**사전 등록 4번 — RSN 3시드 앙상블에 §7 교체 규칙 재적용** (`swap_review.py --cand rsn_ens` → `data/eval/model/swap_review_rsn_ens.json`):

| ① 무해 | 통과 | 홀드아웃 오경보 5.3 → **2.3%** (−3.0%p [−4.9, −1.0] 유의 감소) · gold 재현 78.4 → 80.0%(+1.6 미판정) · 조 F1 38.5 → 42.9%(+4.4%p [+0.1, +8.8]) |
| ② 교체 이유 | **불통과** | 변형문 재현 변화: 현행 −20.7%p · 후보 −13.3%p → 차 +7.4%p [−2.2, +17.0] 미판정 |

- **사전 규칙상 "보류"** — 교체를 검토한 이유(변형문 강건성)가 유의하게 개선되지 않았다
- 그러나 **어느 축에서도 현행보다 나쁘지 않고** 오경보는 사람이 쓴 홀드아웃에서도 유의하게 줄었으며 조 F1이 올랐다. 이것을 교체 이유로 쓰려면
  **새 사전 등록**(예: "기존 승격 규칙 ① 통과 + 오경보 감소")이 필요하다 — 결과를 본 뒤 기준을 바꾸는 것이므로 이번 판정에는 쓰지 않는다
- 서빙 비용 3배(앙상블). 실제 약관 지목률이 절반이 된 것이 오경보 감소인지 위반 누락인지는 정답이 없어 알 수 없다

### 7-3. 새 시험 데이터로 재검증 (사전 등록, 2026-10-06 — 결과를 보기 전에 적음)

**왜 새 데이터인가:** §7-2에서 RSN 앙상블이 "오경보는 줄고 나빠진 곳은 없다"는 것을 **이미 본** 시험셋(gold 255·홀드아웃 12문서·B4·paraphrase)으로
다시 판정하면, 통과할 것을 알고 기준을 고르는 셈이다. 그래서 **아직 아무 모델도 시험받은 적 없는 문서**를 새로 떼어 두고 두 모델을 다시 학습해 거기서만 판정한다.

**새 시험셋 (선정 규칙 고정, `random.Random(20261006)`):**
- 새 위반 시험: gold가 아닌 공정위 사건 문서 570개 중 **20%(114개)** — 그 문서의 공정위 조항 전부. 공정위가 위반으로 인용한 조항이라 **조항 재현**에만 쓴다(조 귀속은 묻지 않는다)
- 새 비위반 시험: 기존 고정 홀드아웃 밖 표준계약서 문서 44개 중 **12개** — 그 문서의 조항 전부(라벨이 아니라 출처로 정의)
- 두 집합의 문서와 그 말투 사본은 **학습·dev에서 모두 뺀다.** 기존 홀드아웃 12문서도 계속 뺀다

**두 모델 (같은 분할·같은 시드 42·7·123, 3시드 앙상블로 비교):**
- **N-C**: KoELECTRA, clean.jsonl(새 시험 문서 제외) — "지금 방식으로 다시 학습했을 때"
- **N-RSN**: RoBERTa, + 회사 말투 음성 사본(새 시험 문서 사본 제외) — 후보

**판정:**
1. **교체 이유 — 오경보 감소:** 새 비위반 시험에서 N-RSN − N-C 오경보 차의 95% CI(문서 군집 재표집 + 시드 분산) 상한 < 0
2. **해 없음 — 재현 유지:** 새 위반 시험에서 N-RSN − N-C 재현 차의 CI 상한 < 0 이면 기각
3. 1 통과 · 2 기각 아님 → **교체 권고.** 그 밖은 현행 유지
4. 보고만(판정 아님): 배포 중인 article_v2와의 비교(⚠ article_v2는 옛 데이터로 학습해 새 시험 문서 일부를 이미 봤을 수 있다 → 현행 쪽에 유리한 편향),
   기존 시험셋(gold·B4·paraphrase·실제 약관), 서빙 비용

**결과 (10-06, `eval/model/fresh_revalidation.py` → `data/eval/model/fresh_revalidation.json`) — 교체 권고 없음, 현행 유지**

새 시험셋: 위반 428조항(공정위 111사건) · 표준계약서 360조항(12문서). 두 모델 모두 이 문서와 그 사본을 학습·dev에서 뺐다. GPU 1.

### 7-4. GPT 반복 실행 — GPT 우위의 실행 변동 확인 (사전 등록, 2026-10-06)

**왜:** E_teacher의 "GPT가 조 F1 4~7%p 앞선다"는 GPT 실행 1~2번에 기댄다. temperature 0에서도 실행마다 약 9%가 달라진다(A vs A').
재현 맞춤 차의 CI 하한이 +0.2%p로 0에 붙어 있어 실행 변동을 넣으면 사라질 수 있다.

**설계:** gpt-4o(명시 지정, `.env` 기본값 무시) · forward 프롬프트 fwd-v5 · temperature 0 · **5회 독립 실행**.
대상 gold clean 255 + 홀드아웃 300(조항 단위 오경보용). 비용 약 15달러(승인 10-06).

**판정:** 각 실행에서 (GPT − article_v2 배포) 조 F1 차와 (GPT − article_v2 재현 맞춤) 조 F1 차를 구하고,
5회 평균 차의 95% CI = 평균 ± 1.96·√(문서 군집 부트스트랩 분산 + 실행 간 분산/5).
CI 하한 > 0 이면 "GPT 우위 확인", 아니면 "실행 변동을 넣으면 미판정". 조항 단위 재현·오경보도 같은 방식으로 보고.

**결과 (10-07, `eval/label/e_teacher_repeat.py --analyze-4` → `data/eval/label/e_teacher_repeat_4runs.json`) — GPT 우위 확인**

**사전 등록 이탈:** OpenAI 크레딧이 두 번 소진돼 10-07 실행은 2회만 끝났다(비용 추정도 낮았다 — 실제 호출당 약 0.008달러, 5회 약 22달러).
같은 조건(gpt-4o·fwd-v5·temperature 0)의 기존 실행 2개(08-30 teacher 캐시, FB-Check v5 forward)를 더해 **4회로 판정**했다(사용자 결정).

| GPT 실행 | 조 F1 | 조항 재현 | 배포 KoELECTRA 대비 | 재현 맞춘 KoELECTRA 대비 |
|---|---|---|---|---|
| 10-07 1회차 | 45.8% | 87.5% | +7.3%p | +5.3%p |
| 10-07 2회차 | 46.5% | 88.2% | +8.0%p | +5.0%p |
| 08-30 | 45.1% | 87.8% | +6.6%p | +4.1%p |
| FB-Check v5 | 46.3% | 88.2% | +7.8%p | +4.8%p |
| **4회 (실행 변동 포함 CI)** | | | **+7.4%p [+3.2, +11.6]** | **+4.8%p [+0.9, +8.7]** |

- **실행 간 표준편차는 0.5~0.6%p**로, 구간 폭은 거의 전부 평가셋(255건) 표본 오차에서 온다. 실행을 늘려도 구간은 거의 줄지 않는다
- 실행 간 조 판정 일치 약 92% (temperature 0에서도 약 8%는 달라진다)
- **결론: GPT의 조 식별 우위(재현 맞춤 약 5%p, 배포 대비 약 7%p)는 실행 변동을 넘는다.** 조항 지목(재현·오경보) 축은 E_teacher대로 동률

## 9. 한계 (논문에 그대로 쓴다)

- 사람 전문가 라벨이 없다. FTC 의결서는 위반 사건만 담고, 음성은 "표준계약서는 적법하다"는 출처 가정에 기댄다. 평가자 간 일치도(κ)는 측정하지 않았다
- 필터 비교 모집단(2,305건)은 사건 단위 근거를 조항마다 복제한 준거다. 최적 상수가 54.4%로 모든 라벨러를 이기므로 절대 F1은 해석하지 않고, 문서 층화 상대 비교만 주장한다
- 오경보는 구간으로만 보고한다(2.3~12.1%). 하류 비교의 홀드아웃은 12문서 300조항이라 MDE가 3~6%p다
- 조 F1은 gold 255로 판정할 수 없다(필요 n≈1,296). 모델 개선 주장은 조항 단위에 한정한다
- 실제 기업 약관 99건에서의 행동 변화는 정답이 없어 채점하지 못했다
- AI Hub 전문가 라벨은 공정위 의결서 가공본이라 gold와 출처가 같다. 텍스트 누수는 제거했지만 같은 규제기관의 판정 경향을 공유한다
