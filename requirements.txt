# `uvicorn backend.api.server:app`이 바로 뜬다 — server.py의 lifespan이 기동 시
# KoE5 임베더(sentence-transformers)를 미리 로드하므로 이게 빠지면 기동 자체가
# sys.exit(1)로 죽는다(README "Getting Started"가 이 파일 하나만 설치하므로
# 반드시 여기 포함되어야 함).
#
# requirements-dev.txt/requirements-ci.txt가 이 파일을 `-r`로 상속하고, 각자
# 필요한 패키지만 추가로 얹는다. 버전은 여기서만 관리한다 — 다른
# requirements-*.txt에는 따로 적지 않는다. Docker(requirements-serve.txt)는
# 더 이상 없음 — 이 파일 자체가 곧 서빙 최소 세트라 Dockerfile도 이 파일을
# 직접 쓴다.
#
# 데이터 수집·전처리·토픽모델링(크롤링, EDA)까지 포함한 전체 개발 환경이 필요하면
